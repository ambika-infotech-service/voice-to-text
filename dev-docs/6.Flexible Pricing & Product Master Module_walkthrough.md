### 2. Dynamic Pricing Engine
- Created [pricing.service.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/services/pricing.service.ts) using the Angular 22 `@Service` decorator.
- Implemented support for the five pricing modes:
  1. `DIRECT_PRICE` (Direct selling price)
  2. `BASE_MINUS_DISCOUNT` (MRP - Discount)
  3. `BASE_MINUS_DISCOUNT_MINUS_CASH` (MRP - Discount - Cash Discount)
  4. `BASE_MINUS_DISCOUNT_MINUS_CASH_PLUS_GST` (MRP - Discount - Cash Discount + GST)
  5. `BASE_MINUS_DISCOUNT_MINUS_CASH_PLUS_GST_PLUS_PROFIT` (MRP - Discount - Cash Discount + GST + Profit)
- Integrated the engine with [calculation.service.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/services/calculation.service.ts) to delegate line-item total calculations.
- Added pricing snapshot audit fields to `InvoiceItem` inside [invoice.model.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/models/invoice.model.ts).

### 3. Upgraded Product Search & Voice Search
- Rewrote [product-search.service.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/core/search/services/product-search.service.ts):
  - Fetches and caches flattened variant objects conforming to the original UI interface.
  - Dynamically builds descriptive display names (e.g. `Prince PVC Pipe 6Kg (63mm, 2", 6 Kg)`).
  - Automatically indexes size inches, millimeters, weight, pressure, schedules, and capacity parameters.
  - Generates synonyms like `"half inch"` for `"1/2"` and translation aliases like `"આશીર્વાદ"` for `"Ashirvad"` so voice search is fast and accurate.
