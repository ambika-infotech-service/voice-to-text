# Walkthrough - Billing Form Enhancements

We successfully implemented both major billing form enhancements to streamline the user experience:

1. **Unified Customer & Contact Search**: Removed the manual toggle and combined customer and business contact searches under a single, unified search input field.
2. **Purchased By Autocomplete Textbox**: Replaced the "Purchased By" select dropdown with an autocomplete textbox that displays default suggestions (linked workers/contacts and "Self (Owner)") and queries both linked contacts and global workers dynamically as the user types.
