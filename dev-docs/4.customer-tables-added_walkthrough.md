## Changes Made

### 1. Database Schema (Migration V2)
- Added [migration-v2.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/core/database/migrations/migration-v2.ts) containing table definitions for:
  - `customers` (enforces name requirements via db-level CHECK constraints and uniqueness on optional mobile columns).
  - `customer_workers` (establishes foreign key mappings with `ON DELETE CASCADE`).
- Added database indexes to speed up search routines on `customer_name`, `company_name`, and contact mobile.
- Updated `database.ts` to register `MigrationV2` and bumped `DB_VERSION` to `2` in `database.constants.ts`.

### 2. Entity Models & Interfaces
- Defined TypeScript interfaces in:
  - [customer.model.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/core/database/models/customer.model.ts)
  - [customer-worker.model.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/core/database/models/customer-worker.model.ts)

### 3. Database Repositories & Services
- Created [customer.repository.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/core/database/repositories/customer.repository.ts) providing:
  - Clean CRUD interfaces for both tables.
  - Multi-condition, prioritized search query utilizing SQL `CASE` statements to rank exact matches first, starts-with matches second, and contains matches third.
  - Transaction blocks (`runTransaction`) ensuring customer and worker rows are saved/updated inside a single transaction context.
  - Normalization helpers to write empty contact fields as `null` values.
- Implemented high-level orchestration in [customer.service.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/customers/services/customer.service.ts) wrapping DB interactions in try-catch alert logic.
