# Walkthrough: Mobile-First Layout & Styling Updates

This document summarizes the changes made to optimize the Voice-to-Text invoice generator and Hardware ERP system for a high-quality mobile user experience.

## Changes Made

### 1. Global Shell & Icon Support
- **[index.html](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/index.html)**: Added Google Fonts (Plus Jakarta Sans) and loaded Bootstrap Icons CDN so that icons in templates display correctly.
- **[styles.scss](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/styles.scss)**:
  - Configured custom cyan/teal variables (`#6adef7`) for primary branding accents.
  - Overrode Bootstrap `.text-primary`, `.bg-primary-subtle`, and `.btn-primary` utility classes to style the app in cyan while maintaining accessible color contrast (dark `#0f172a` text on cyan buttons and deep teal `#007c91` on white backgrounds).
  - Set touch heights to a minimum of `44px` on mobile for inputs, buttons, and dropdowns (meeting WCAG AA targets).
  - Created a `.responsive-card-table` helper class to dynamically stack standard HTML tables into vertical cards on screens `< 768px`.
  - Added button hover scales, custom focus shadows, and scroll padding-bottom to avoid sticky bar cutoff.
- **[app.html](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/app.html)**:
  - Rendered a modern header bar containing a visual database status badge.
  - Implemented desktop-only header tabs (`d-none d-md-flex`) and a sticky, touch-friendly mobile bottom navigation bar (`d-md-none`).

### 2. Segmented Mobile Switcher on Billing Page
- **[billing-page.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/pages/billing-page/billing-page.ts)**: Added an `activeMobileView` signal to toggle view modes between the form editor and the A4 print sheet.
- **[billing-page.html](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/pages/billing-page/billing-page.html)**:
  - Placed a segmented tab controller at the top for screens `< xl`.
  - Conditionalized `<app-invoice-form>` and `<app-invoice-preview>` using native class bindings (`[class.d-none]`) to eliminate the duplicate instance of `app-invoice-preview` previously used for mobile fallbacks. Both forms now load a single component instance.

### 3. Responsive Card Stacking
- **[invoice-row.scss](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/components/invoice-row/invoice-row.scss)**:
  - Applied CSS Grid to `:host` (table row) and cells (`td`) on screens `< 768px` to reflow raw inputs into an aligned card structure.
  - Added mobile CSS labels for Qty, Unit, Rate, and Total Amount using `::before` pseudo-elements.
  - Styled an active recording state with a glowing pulse animation (`@keyframes mic-pulse`) on listening buttons.
- **[customer-list.component.html](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/customers/pages/customer-list/customer-list.component.html)** & **[contact-list.component.html](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/business-contacts/pages/contact-list/contact-list.component.html)**:
  - Added `.responsive-card-table` class to listing tables.
  - Set `data-label` attributes to table cells (`td`) to render titles above stacked card fields on small viewports.
