# Walkthrough - Intelligent Product Search Engine

We have successfully implemented the intelligent Product Search Engine feature in our Angular 22 + Capacitor SQLite application. The implementation converts user voice-to-text strings (and manual inputs) into ranked, highly matched products from the local SQLite database.

## Changes Made

We introduced five new files under the directory [src/app/core/search](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/core/search):

1. **Models and Interfaces**:
   - [search.model.ts](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/core/search/models/search.model.ts): Declares TypeScript types for search results, normalizer rules, in-memory product models, and extensible scoring rules.

2. **Normalization Utility**:
   - [normalization.ts](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/core/search/utils/normalization.ts): Configures an extensible processing pipeline that converts search input to lowercase, removes punctuation without stripping non-English letters (such as Gujarati and Hindi), translates unit variants (e.g. `twenty`, `20 litre`, `20 ltr` -> `20l`), and trims whitespace.

3. **Fuzzy Match Engine**:
   - [levenshtein.ts](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/core/search/utils/levenshtein.ts): Implements a high-performance Levenshtein Distance edit distance calculator and similarity matcher in pure TypeScript.

4. **Extensible Scoring Rules**:
   - [scoring.ts](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/core/search/utils/scoring.ts): Defines default modular scorers for name matches, alias matches, brand/category matches, keyword count, substring lookups, and fuzzy typo corrections.

5. **Search Engine Service**:
   - [product-search.service.ts](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/core/search/services/product-search.service.ts): Integrates in-memory caching to prevent redundant database hits, coordinates the 11 matching stages, handles tie-breakers, registers modular scoring processors, and formats final outputs according to confidence boundaries.

6. **Unit Tests**:
   - [product-search.spec.ts](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/core/search/services/product-search.spec.ts): Exercises all utilities, normalization pipelines, fuzzy algorithms, shortcuts, scoring engines, confidence boundaries, and extensible scoring plugins.

7. **Invoice Billing Integration**:
   - [invoice-form.ts](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/features/billing/components/invoice-form/invoice-form.ts): Runs `ProductSearchService` on speech recognition completion. Auto-fills item details (name, unit, selling price) if confidence > 90%, otherwise loads the search string to pop up suggestions.
   - [invoice-row.ts](file:///Users/smitpatel/Desktop/Personal Projects/voice-to-text/src/app/features/billing/components/invoice-row/invoice-row.ts): Integrates async autocomplete powered by `ProductSearchService` and handles automatic dropdown toggling (closes if matching an exact product name, opens on partial matched queries).
