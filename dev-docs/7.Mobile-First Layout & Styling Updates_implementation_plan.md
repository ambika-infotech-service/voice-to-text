# Mobile-First User Experience & Premium Design Updates

This plan details the implementation strategy to optimize the Hardware Store ERP & Voice-to-Text Invoice Generator application for mobile viewports. The updates ensure a premium, touch-friendly, high-fidelity experience on mobile phones while preserving full desktop functionality.

## User Review Required

> [!IMPORTANT]
> - We will introduce a **bottom navigation bar** for viewports under 768px (mobile phones) which matches typical native iOS/Android tab navigation. On desktop, a clean header and top navigation pill container will be rendered.
> - We will modify the **Billing Page** to use a mobile segmented control (toggle tab) allowing users to switch between the **Edit Form** and **A4 Preview** on mobile viewports. On desktop, they will remain side-by-side. This solves the vertical scroll constraint.
> - Tables in Customer Management, Business Contacts, and Invoice Row items will automatically stack into card formats on mobile screens.

## Open Questions

> [!NOTE]
> No immediate blockers have been identified. Emojis and Bootstrap Icons will be combined for the bottom tab bar navigation. We will import Bootstrap Icons CSS from a CDN in `index.html` to guarantee that all icon elements render correctly.

## Verification Plan

### Automated Tests
- Build verification: `npm run build`
- Unit tests: `npm run test`

### Manual Verification
- Resize the browser viewport to mobile dimensions (e.g. 375px width) and verify:
  - Bottom navigation bar behaves correctly, has touch targets, and shows active highlights.
  - Billing page form-vs-preview toggle switcher shifts seamlessly and resolves long scroll pages.
  - Table records in lists dynamically reflow into distinct cards with labels on mobile, and revert back to tables on desktop.
  - Form inputs are accessible, readable, and touch targets are easy to click.
