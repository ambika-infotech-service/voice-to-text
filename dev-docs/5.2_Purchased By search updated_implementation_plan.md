# Implementation Plan - Purchased By Autocomplete Textbox

Introduce a textbox with autocomplete suggestions for the "Purchased By" field. The field will display a dropdown showing default options (linked workers/contacts and "Self (Owner)") and dynamic search results combining linked and global workers when the user types.

## Proposed Changes

### Billing Component

#### [MODIFY] [invoice-form.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/components/invoice-form/invoice-form.ts)
- Add signals for the Purchased By autocomplete state:
  - `showPurchasedByDropdown` (signal<boolean>)
  - `purchasedBySearchQuery` (signal<string>)
  - `filteredPurchasedByResults` (signal<any[]>)
- Add an effect that monitors `purchasedBySearchQuery`:
  - If empty: show `Self (Owner)` and all customer-linked contacts (`customerContacts()`) as defaults.
  - If text is entered: filter linked contacts locally and search global business contacts/workers via `businessContactService.searchContacts`, combining the results.
- Listen to value changes on the `purchasedBy` form control to set the search query signal.
- Implement selection handler `selectPurchasedByResult(item)` and UI event handlers `onPurchasedBySearchInput`, `onPurchasedByFocus`, and `onPurchasedByBlur`.

#### [MODIFY] [invoice-form.html](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/components/invoice-form/invoice-form.html)
- Replace the `<select>` element for `purchasedBy` in the customer section with a text `<input>` field.
- Bind the input to `onPurchasedBySearchInput`, `onPurchasedByFocus`, and `onPurchasedByBlur`.
- Render a suggestions dropdown with badges distinguishing "Linked Contact" from "Global Worker".
