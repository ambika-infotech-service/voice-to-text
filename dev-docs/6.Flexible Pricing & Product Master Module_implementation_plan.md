# Implementation Plan - Flexible Pricing & Product Master Module

Introduce a scalable database schema, a robust pricing calculation engine, a rich seed database (~200 variants), and upgraded search capabilities to support multi-attribute hardware queries (sizes, schedules, weight, pressure) and supplier price lists.

## User Review Required

> [!IMPORTANT]
> The database schema changes require dropping and recreating the core product and category tables to support normalized relationships (Category, SubCategory, Brand, Product, ProductVariant, PriceList, and PricingRule). Existing dummy product data will be replaced with realistic seed data (~200 variants) based on the supplier catalogs.

## Open Questions
None. The specifications provided in the request cover the full mathematical pricing formulas, categories, and variants.

### Pricing Engine Service

#### [NEW] [pricing.service.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/services/pricing.service.ts)
- Define `PricingService` with the `@Service()` decorator.
- Implement functions:
  - `calculatePurchasePrice(basePrice, discountPercent, cashDiscountPercent, gstPercent, profitPercent, extraCharges, roundOff, pricingType)`
  - `calculateSellingPrice(basePrice, discountPercent, cashDiscountPercent, gstPercent, profitPercent, extraCharges, roundOff, pricingType)`
  - `calculateGST(basePrice, discountPercent, cashDiscountPercent, gstPercent, profitPercent, extraCharges, roundOff, pricingType)`
  - `calculateProfit(basePrice, discountPercent, cashDiscountPercent, gstPercent, profitPercent, extraCharges, roundOff, pricingType)`
  - `calculateFinalAmount(sellingPrice, quantity)`
- Implement pricing formulas matching enums:
  - `DIRECT_PRICE`: Rate is direct (no discount, gst, profit calculations).
  - `BASE_MINUS_DISCOUNT`: basePrice - discountPercent + extraCharges.
  - `BASE_MINUS_DISCOUNT_MINUS_CASH`: (basePrice - discount) - cashDiscount + extraCharges.
  - `BASE_MINUS_DISCOUNT_MINUS_CASH_PLUS_GST`: ((basePrice - discount) - cashDiscount) + GST + extraCharges.
  - `BASE_MINUS_DISCOUNT_MINUS_CASH_PLUS_GST_PLUS_PROFIT`: (((basePrice - discount) - cashDiscount) + GST + extraCharges) + Profit + roundOff.
