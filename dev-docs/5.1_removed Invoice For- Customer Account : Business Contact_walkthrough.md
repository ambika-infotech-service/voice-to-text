# Walkthrough - Unified Customer & Business Contact Search

We successfully implemented a unified search field for the Invoice creation form. This replaces the manual billing category toggle (radio buttons) with an intelligent, single lookup box.

## Changes Made

### Billing Component

#### [invoice-form.ts](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/components/invoice-form/invoice-form.ts)
- Removed individual search queries (`customerSearchQuery`, `contactSearchQuery`) and dropdown states.
- Implemented unified signals `searchQuery`, `showDropdown`, and `filteredResults`.
- Created a single combined search effect that fetches suggestions from both `CustomerService` and `BusinessContactService` and combines them, mapping and tagging them with distinct types (`customer` vs. `business_contact`).
- Streamlined form initialization and selection mapping, updating validators on the fly depending on the selected entity type (e.g., mobile number is required for customer accounts but optional for business contacts).

#### [invoice-form.html](file:///Users/smitpatel/Desktop/Personal%20Projects/voice-to-text/src/app/features/billing/components/invoice-form/invoice-form.html)
- Removed the "Invoice For" radio button toggle block.
- Updated the "Customer Name" field layout to be common and render a unified dropdown.
- Configured customer-specific and contact-specific sections to render conditionally based on the type of the selected search result.
